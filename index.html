Rules Summary

  • Draw 6 to bring a marble out of home.
  • Click a highlighted marble to move it.
  • Landing on an opponent sends them home.
  • Safe cells cannot be captured.
  • Exact roll required to reach final finish.
  • Rolling a 6 grants an extra turn.

README

This is a Marble Ludo-style browser game built with HTML, CSS, and vanilla JavaScript. It supports 2–4 players, turn-based play, home/start zones, safe cells, finish lanes, capture mechanics, exact-finish movement, and win detection.

Core Game Logic

Each marble stores a logical step position rather than relying on fragile visual movement. A marble can be:

  • Home: not yet entered the track
  • 0 to mainTrackLength - 1: on the main track
  • mainTrackLength to mainTrackLength + finishLength - 1: in the player's finish lane
  • Completed: reached the final finish cell

When a draw happens, the game calculates valid moves by checking each marble’s current state and simulating the exact destination. Only marbles with legal moves become selectable. This prevents the earlier bug where marbles could be drawn but not moved correctly after valid draws.

GitHub Upload Instructions

  1. Create a new repository on GitHub.
  2. Save these three files into your project folder:
    • index.html
    • style.css
    • script.js
  3. Open a terminal in the folder and run:
git init
git add .
git commit -m "Initial Marble Ludo game"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main

GitHub Pages Deployment

  1. Open your GitHub repository.
  2. Go to Settings → Pages.
  3. Under Build and deployment, set:
    • Source: Deploy from a branch
    • Branch: main and /root
  4. Save the settings.
  5. Wait a minute for deployment, then open the generated GitHub Pages URL.
